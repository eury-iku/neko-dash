# ねこダッシュ — Neko Dash

猫を操作して、四方から飛んでくる障害物を避けるシンプルな2Dアクションゲームです。  
HTML / CSS / JavaScript のみで動作します。

## Demo

GitHub Pagesで公開後、ここにURLを記載します。

https://eury-iku.github.io/neko-dash/

## Features

- 矢印キー / WASD 操作
- スマホ向けタッチ操作
- スコア機能
- ハイスコア保存
- レベル上昇
- 3種類の障害物
  - Normal
  - Sway
  - Fast
- スタート画面
- ゲームオーバー画面

## How to Play

PC:

- Arrow Keys または WASD で移動
- Enter / Space でスタートまたはリスタート

Mobile:

- 画面下部の方向ボタンで移動

## Tech Stack

- HTML
- CSS
- JavaScript
- localStorage
